# Travel Bot V3

## Что изменилось
- Новое главное меню:
  - Маршрут сегодня
  - Маршрут завтра
  - Выбрать дату
  - Весь маршрут
  - Добавить в маршрут
- У сегодня и завтра есть выбор: Кратко / Подробно
- У выбора даты сначала показываются даты без нумерации, потом формат: Кратко / Подробно
- В подробном дне есть кнопки:
  - Общий маршрут
  - Расписание
  - Еда
  - Что посещаем
  - Что важно
- В блоках используются HTML-гиперссылки в названиях мест
- В разделе "Что посещаем" можно проваливаться в отдельные карточки мест
- Для 1 мая добавлены карточки The Yard Hotel Beijing и Xianyukou Street с фото

## Добавление в маршрут
Напиши сообщением:

```text
добавь 7 мая посещение магазина с пряжей
```

## Запуск
```bash
pip install python-telegram-bot==22.5
export TELEGRAM_BOT_TOKEN='YOUR_TOKEN'
python bot.py
```

## Важно
- Сегодня и завтра пока в тестовом режиме привязаны к 1 и 2 мая
- Фото карточек мест отправляются через `send_photo`
- Для части мест детальные карточки пока есть не для всех, сейчас полноценно заполнены первые 2 точки на 1 мая
