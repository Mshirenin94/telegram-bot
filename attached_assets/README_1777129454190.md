# Travel Bot V4

## Что исправлено
- Исправлена логика карточек мест: теперь после нажатия на место бот отправляет отдельное сообщение с фото и описанием
- Переименованы разделы:
  - `Коротко` -> `Общая информация`
  - `Подробно` -> `Подробная информация`
- Внутри подробного дня кнопка `Общий маршрут` теперь снова отправляет пакет сообщений:
  - общий overview
  - расписание
  - еда
  - что посещаем
  - что важно
- В разделе `Еда` появилось отдельное меню мест и расширенные описания
- В разделе `Что посещаем` оставлено меню мест с фото и детальным текстом

## Что уже расширено
- Карточки мест с фото для нескольких важных точек первых дней
- Расширенные food descriptions для Bianyifang, Siji Minfu, Haidilao, Myeongdong Kyoja, La Yeon

## Запуск
```bash
pip install python-telegram-bot==22.5
export TELEGRAM_BOT_TOKEN='YOUR_TOKEN'
python bot.py
```
