# Travel Bot V5

## Что изменено
- Исправлен сценарий детальных карточек с фото: бот теперь сначала скачивает изображение локально и отправляет файл, а не внешний URL
- При входе в `Подробная информация` день больше не раскрывается автоматически, показывается только меню разделов
- `Общий маршрут` переименован в `Общий план дня`
- В `Общий план дня` пакет сообщений приходит только по нажатию этой кнопки
- Добавлена автоматическая простановка `map_link` для всех мест без ссылок:
  - China -> AMap search link
  - South Korea -> KakaoMap search link
- В разделах `Еда` и `Что посещаем` гиперссылки подставляются по всем доступным местам из CSV
