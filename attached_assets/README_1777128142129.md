# Travel Bot MVP

## Что внутри
- `bot.py` — MVP Telegram-бота на `python-telegram-bot`
- `itinerary_mvp.json` — маршрут по дням
- `places_enriched_v1.csv` — справочник мест со ссылками

## Что умеет MVP
- `/start`
- Кнопка "Сегодня"
- Кнопка "Выбрать дату"
- Кнопка "Весь маршрут"
- Кнопка "Полезные ссылки"

## Установка
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install python-telegram-bot==22.5
export TELEGRAM_BOT_TOKEN='YOUR_NEW_TOKEN'
python bot.py
```

## Важно
- В коде по умолчанию кнопка `Сегодня` сейчас ведёт на день 1 как тестовый режим.
- Потом можно привязать дату автоматически к `datetime.now()` и часовому поясу Asia/Seoul / Asia/Shanghai.
- Для общего чата просто добавь бота и нажми `/start`.
- Чтобы узнать `chat_id`, используй `getUpdates` после сообщения в чат.
