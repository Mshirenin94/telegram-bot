# Travel Bot V2

## Что нового
- Кнопка **Сегодня кратко** оставлена как в MVP
- Кнопка **Сегодня подробно** отправляет подробную версию дня отдельными сообщениями
- Подробная версия разбита на блоки:
  - Расписание по часам
  - Еда
  - Что посещаем
  - Что важно
- Можно добавлять свои пункты в план сообщением

## Формат для добавления
Напиши боту сообщение:

```text
добавь 7 мая посещение магазина с пряжей
```

После этого запись сохранится в `user_notes.json` и будет видна в подробной версии этого дня.

## Запуск
```bash
pip install python-telegram-bot==22.5
export TELEGRAM_BOT_TOKEN='YOUR_TOKEN'
python bot.py
```

## Ограничения текущей версии
- Кнопки `Сегодня кратко` и `Сегодня подробно` пока открывают день 1 как тестовый режим
- Для реальной поездки позже можно привязать текущую дату к нужному дню маршрута
